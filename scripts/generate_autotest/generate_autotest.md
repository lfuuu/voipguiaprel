# Описание скрипта

generate_autotest.py - скрипт создания и удаления автотестов между городами.

В generate_autotest.py встроен хелп вызывающийся по ./generate_autotest.py -h

Для работы скрипта нужен конфигурационный json файл с одним значением "db":"параметры подключения к БД"

Пример
```
{
    "db":"host=127.0.0.1 dbname=nispd_test"
}
```

Скрипт может:
1. Создать автотесты и добавить в БД : ./generate_autotest.py -c conf.json
2. Удалить автотесты из БД : ./generate_autotest.py -c conf.json -delete
3. Создать автотесты, но не добавлять их в БД (запуск вхолостую) : ./generate_autotest -c conf.json -dry

# Описание ТЗ

Для создания автоматических тестов между нашими городами нужно из карточки стата 652 офисные номера городов заведенных в воипроутинге и сделать тесты звонков каждый с каждым
  
Обозначения:
* А : город оригинатор
* B : город терминатор
* s : сокращенное название города
* XX : номер астериска
* FO : федеральный округ куда уходит звонок

## Тесты в городе оригинаторе

1. * Название теста : To_%B_ast
   * Название транка : %s_mcn_astXX
   * А номер
   * В номер
   * Результат : %s_mcn_mgmn_loop (его можно взять и общих настроек города)

1.1 Для Москвы название транка mcn_msk_ast16, А номер В номер рерультат, ECSS_%FO.*

2. * Название теста To_%B
   * Название транка : результат выполнения теста 1
   * А номер
   * В номер
   * Результат ECSS_%FO.*

2.1 В Москве этого теста не будет

## Тесты в городе терминаторе

3. * Название теста : From_%A
   * Название транка : результат выполнения теста 2
   * А номер
   * В номер
   * Результат %s_mcn_mgmn_loop (его можно взять и общих настроек города)

3.1. В Москве этого теста не будет

4. * Название теста : From_%A_ast
   * Название транка : результат выполнения теста 3
   * А номер
   * В номер
   * результат : проставим руками (результат будет динамический) или сделать анализ результа по регулярному выражению RC_s%_MCN_AstXX

4.1 Для Москвы название транка результат выполнения теста 1, для москвы регулярное вырожение будет mcn_msk_ast.*
